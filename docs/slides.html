The problem: nine distinct squares in a 3×3 magic square?

Centre entry y². Each line through the centre is a Pythagorean triangle on hypotenuse y ⇒ a point of the rational unit circle T(Q).

Magic ⇔ four sines of integer combinations of the angles have magnitudes {a, b, a+b, a−b}.

Rigidity conjecture: for every full-depth frequency matrix this never happens on T(Q)^r. Strictly stronger than "no magic square of squares".

Proved in the paper

  • r = 2, exponent sum ≤ 7: 2,064 exact certificates
  • D1 ⇔ extra rational point on a genus-5 curve
  • r = 4: nothing at projective height ≤ 4 (11,862 configurations)
  • 48 Hadamard surfaces are of general type

Open: the eight-point list (Conj 7.3), sum ≥ 8, the torsion-coset hypothesis (Conj 8.6), ten orbits.

Step 2 — a team, not a pipeline

The loop: convert → ledger → attack → referee → absorb → iterate

Ledger. Every open target typed: certificate-extension, bounded-search, hypothesis-probe, structural. State, acceptance, best tag, next increment.

Playbooks. Paper-agnostic strategies with acceptance criteria and failure modes. Type → playbook → agent.

Planner. propose_next_attack(P1) → "exponent sum 9, this command, this cost, this stop rule".

Referee contract. tag_lint.py fails the build if any claim lacks a tag, an evidence file, a verifier, or a passing stage.

Absorb. Accepted results become stages 17+ of the paper's own verification suite, run by the paper's own runner. The paper stays byte-identical.

Iterate. Iteration 2 (sum 9, height 4) was launched by the planner's own commands before the deadline.

Findings 2–5 — pushing the certified region, and learning from a failure

Certificate extender. Theorem 1.1 extended from exponent sum 7 to 8 (iteration 1: 3,600 systems, checker PASS 133 s, SymPy cross-check 75/75) and to 9 (iteration 2, by the planner's command: 5,520 systems, 553,392 exact determinants, checker PASS 305 s). MACHINE-VERIFIED

Torsion prober. Conjecture 8.6 tested on 273,024 exact rational solutions at height ≤ 3 and 662,528 at height ≤ 4 and 1,916,672 at height ≤ 5 (all 113 orbits, 48 systems): 0 off a torsion coset, 0 admissible. Iteration 1 proposed a sharper form (rank ≤ 2); iteration 2 refuted it (rank-3 points in two orbits). The loop corrected itself. SEARCH-EVIDENCE

Point hunter. Sieved exact search: no new point on C to height 1,000,000 (500 billion pairs, 6 min), none on the genus-2 quotient to 300,000; 12 small points on E₀, none lifting. SEARCH-EVIDENCE

From the failure, a lemma. A zero sine on row r is the relation Ar; equal magnitudes on rows i, j give Ai ± Aj. So degenerate points lie on torsion cosets, rank ≤ 3, and rank 3 needs Ai ± Aj ∥ Ar. Criterion true in 23/113 orbits, including the two that showed rank 3; all rank-3 points explained. PROVED MACHINE-VERIFIED

Trichotomy. On a signed system the magnitudes are forced to be {A, B, A+B, A−B}, so a rational solution is admissible, has a vanishing sine, or has A = 2B. All 1,916,672 recorded points at height ≤ 5 have a vanishing sine; 0 of type A = 2B. One hypothesis, vanishing-sine rigidity, implies both conjectures (it is strictly stronger than 8.1) and names the next search: A = 2B points. PROVED SEARCH-EVIDENCE CONJECTURAL

Why now: candidate theorems are cheap, verified status is not

October 2026, openai/math: 719 AI-generated manuscripts on 372 open problems. About 42% formalized in Lean. The rest "could have issues". Three withdrawn within a day.

The bottleneck has moved from producing theorems to making each claim's status explicit, checkable and correctable.

This loop: every claim carries a referee tag; one command reproduces everything; verbatim transcripts with hashes; corrections recorded in a history; formalization status stated per result (0% today, candidates with exact statements).

And it caught its own false sharpening before anyone else had to.

Beyond magic squares

What the loop needs from a problem: code or certificates to bind tools to; open targets that can be typed; a verification suite to absorb into.

What it validated today: new, independently checked mathematics on a real open problem in one afternoon; its own mistakes caught (a false sharpening, an overflow guard, a quoted rank, two unfinished reports); everything reproducible from one command with hashes.

What it did not: close a conjecture; run on a second paper.

Next instances: the paper's other six targets (planner already emits them); quadratic Chabauty on the genus-2 quotient; any "proved for N ≤ N₀ by certificate" paper; any curve with a conjecturally complete point list; any "every solution has property X" hypothesis.

Manuscript v3 with the new theorem, propositions and lemma, authors Samieinejad and Wolinski, each addition tied to its evidence.

What moved, and what is next

Theorem 1.1: exponent sum 7 → 8 → 9, by the paper's own method, independently checked at each step; the second step was launched by the loop's planner.

Conjecture 7.3: unchanged, but its obstruction is now precise: three rank-1 elliptic quotients; it is a quadratic-Chabauty problem.

Conjecture 8.6: first systematic evidence, 662,528 points at height ≤ 4, no exception; a candidate sharpening proposed by iteration 1 was refuted by iteration 2.

Next computation: quadratic Chabauty on D with the generators of 492.b1 and 1968.j1; then the ten orbits through the same quotient analysis.
