# Elementary real-angle obstruction used for projective boundaries

For real x,z put X=|sin x|, Z=|sin z|, P=|sin(x+z)|, Q=|sin(x-z)|.
Their values cannot be the four distinct positive numbers {a,b,a+b,a-b} with
a>b>0 and a!=2b.

Sine addition gives

\[
P^2Q^2=(X^2-Z^2)^2,\qquad
P^2+Q^2=2(X^2+Z^2-2X^2Z^2).
\]

There are six choices for the unordered pair {P,Q}. The residual of the first
identity is:

| {P,Q} | P^2 Q^2-(X^2-Z^2)^2 |
|---|---|
| {a,b} | -15 a^2 b^2 |
| {a,a+b} | 3 a^2 b(2a-b) |
| {a,a-b} | -3 a^2 b(2a+b) |
| {b,a+b} | -3 a b^2(a-2b) |
| {b,a-b} | -3 a b^2(a+2b) |
| {a+b,a-b} | 0 |

The first five are nonzero under the assumptions. In the last case the residual
of the second identity is 4a^2 b^2 !=0. Thus all six choices are impossible.

Consequently a frequency configuration {v,w,v+w,v-w}, up to individual signs,
has no nondegenerate real-angle solution: substitute x=v.theta,z=w.theta.
This is a proof of the identity-based obstruction, not a historical novelty claim.
